# Piper runtime

Текущий DEB 0.1.1-3 и исходные архивы **не содержат Piper runtime или модели
голосов**. Озвучка остаётся дополнительной локальной возможностью. Порядок
установки в отдельное пользовательское Python-окружение приведён в разделе
[«Озвучка» руководства](MANUAL.md#озвучка). Не устанавливайте Piper через
`sudo pip` в системный Python Debian.

Восстановленный код распознаёт явно заданный `PIPER_PYTHON`, стандартное
пользовательское окружение Piper и ранее установленный приватный runtime.
Это не означает, что runtime включён в пакет. Приложение не устанавливает
Python-пакеты автоматически при запуске.

Старые сценарии сборки комплектного runtime в сохранённый DEB не входили
и не восстановлены. Текущий единый сценарий `packaging/build.py` собирает
приложение с отдельными системными зависимостями; переменная
`MALFERMA_PIPER_BUNDLE` не является его поддерживаемой опцией.

Перед возможным будущим включением Piper в дистрибутив потребуется
согласованный набор нативных зависимостей для целевой архитектуры,
уведомления и соответствующие исходники всех распространяемых компонентов,
включая используемые Piper части eSpeak NG. Нужны также фактическая проверка
импорта и синтеза, инвентаризация файлов и отдельная проверка лицензий
каждой модели. Такие проверки для текущего пакета не заявлены.

Источники и ограничения сохранённого каталога голосов:
[PIPER_LICENSES.md](PIPER_LICENSES.md).
