# Логотип Malferma Libro

Сине-золотой логотип предоставлен владельцем проекта. Для небольших значков
используется эмблема без надписи; полный логотип содержит название.
Логотип и производные значки — **GPL-3.0-or-later** с подтверждения владельца
17 октября 2026 года. Запись разрешения — в [LOGO_LICENSE.md](LOGO_LICENSE.md).

| Доступные файлы | Назначение |
| --- | --- |
| `src/malferma_libro/assets/branding/logo.svg` | Редактируемый полный векторный логотип |
| `src/malferma_libro/assets/branding/app-icon.svg` | Векторная эмблема без надписи |
| `src/malferma_libro/assets/branding/logo.png` | Полный растровый логотип |
| `src/malferma_libro/assets/branding/app-icon.png` | Растровая эмблема |
| `src/malferma_libro/assets/branding/io.github.otkrytaya_kniga.Reader.*` | Те же значки для поиска по стабильному имени приложения |
| `data/icons/hicolor/scalable/apps/io.github.otkrytaya_kniga.Reader.svg` | Масштабируемый значок рабочего стола |
| `data/icons/hicolor/<размер>/apps/io.github.otkrytaya_kniga.Reader.png` | Значки от 16 до 512 пикселей |

SVG содержат замкнутые векторные контуры, включая контуры букв. Они не
требуют внешних шрифтов или сетевых ресурсов и не содержат встроенных
JPEG/PNG. Их можно редактировать непосредственно в векторном редакторе.
Цвета логотипа не навязываются интерфейсу или странице книги.

При восстановлении из сохранённого DEB были доступны установленные
SVG/PNG, но не отдельный исходный JPEG, растровый мастер эмблемы и прежние
сценарии экспорта. Эти материалы не заявляются как восстановленные.
Обычная сборка использует доступные значки и не требует ImageMagick
или Potrace. Манифест текущих изображений приведён в LOGO_LICENSE.md.

На верхней панели нет отдельного логотипа или повторяющейся кнопки разделов.
Разделы доступны в главном меню; значок приложения сохранён в меню рабочего
стола, заголовке и ресурсах приложения.

Каталог исходников — `malferma-libro`, модуль Python — `malferma_libro`.
Пользовательская команда и бренд — `malferma-libro` и **Malferma Libro**.
Стабильный идентификатор `io.github.otkrytaya_kniga.Reader` сохранён для
совместимости: это идентификатор и имя файлов значков, а не старый каталог
исходников.
